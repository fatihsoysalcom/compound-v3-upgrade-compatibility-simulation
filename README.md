# Compound V3 Upgrade Compatibility Simulation

This example simulates a simplified DeFi lending protocol, demonstrating how an upgrade (like Compound V3) can alter key parameters such as collateral factors and interest rates. It illustrates the impact of these changes on a user's borrowing power and outstanding debt, highlighting the need for a compatibility review when a protocol evolves.

## Language

`python`

## How to Run

Save the code as `main.py` and run it from your terminal using `python main.py`.
